# cdCTF — Interactive Pitch Deck (Pitch Day 3.0)

Kiberxavfsizlikni amalda o'rganish bo'yicha O'zbekistondagi birinchi milliy poligon — **cdCTF** loyihasining rasmiy interaktiv Pitch Deck taqdimoti.

## Bo'limlar (Mundarija)
1. **Muqova / Brand**: cdCTF umumiy tavsifi va asosiy ko'rsatkichlar.
2. **01. Muammo**: O'zbekiston kiber-ta'limidagi 3 asosiy to'siq (quruq nazariya, qimmat xorijiy platformalar, mutaxassislar tanqisligi).
3. **02. Yechim**: Brauzerda ishga tushuvchi Docker laboratoriyalari va interaktiv flag tekshirish tizimi.
4. **03. Jamoa**: 2 nafar asoschi — **Hikmatbek** (Founder / Lead Software Engineer) va **Bobur Qadamov** (CEO / CyberSecurity Lead).
5. **04. Nega Aynan Biz?**: Dasturchi + pentester sinergiyasi, real Bug Bounty tajribasi, ishlayotgan jonli tizim.
6. **05. Mahsulot Arxitekturasi**: Texnologik stek va xavfsiz Docker sandbox arxitekturasi.
7. **06. Yo'l Xaritasi**: v0.1 dan v1.5 gacha bo'lgan rivojlanish bosqichlari.
8. **07. Amalga Oshirish Rejasi**: 3 bosqichli amaliy strategiya.
9. **08. Demo Video & Jonli Prototip**: 16:9 demo-video, daqiqama-daqiqa tavsif va `https://cdctf.uz` jonli prototipiga to'g'ridan-to'g'ri havolalar.

## Boshqaruv

- `F`: To'liq ekran (Fullscreen) rejimi.
